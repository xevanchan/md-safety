# Decision records

Short notes on decisions that would be hard to reverse: tooling, data formats, external
services, architecture. One file per decision, numbered in order, never edited after the
fact (add a new record that supersedes the old one instead).

Template for `NNNN-short-title.md`:

```markdown
# NNNN. Title

Date: YYYY-MM-DD
Status: Accepted | Superseded by NNNN

## Context
What situation or problem prompted this.

## Decision
What we decided, in one or two sentences.

## Consequences
What becomes easier, what becomes harder, what we have to remember.
```
